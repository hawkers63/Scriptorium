0. What I reviewed
------------------
v2.5 is a single 2,277-line CustomTkinter app. Closing with "minimise to
tray" withdraws the window and starts a pystray.Icon on a daemon thread
(_minimise_to_tray, line 2226). There is no mutex, lock file, or
FindWindow check, so a second launch (Scriptorium.bat, the .exe, or the
HKCU Run autostart command while an instance is already sitting in the
tray) creates a second process and a second tray icon.

The window never calls iconbitmap / iconphoto. Title bar, Alt+Tab and the
taskbar therefore show the default Tk feather. The packaged .exe is a
separate path: scriptorium.spec sets icon="icon/icon-96.ico", which is
not the file on disk.

On disk today, C:\Scriptorium\icon\ holds only:

  Scriptorium-256.ico   (67,646 bytes)   -- the one Mark wants top-left
  Scriptorium-96.ico    (38,078 bytes)

There is no icon-96.png and no icon-96.ico. _minimise_to_tray still
opens resource_path("icon/icon-96.png") (line 2238). From source that
open fails and the method returns without withdrawing -- so a source
run cannot actually reach the tray. A packaged .exe that still bundles
the old PNG can, which is how multiple tray icons appear in practice.

2. One instance, one tray icon (requested)
------------------------------------------
Why
    Each process owns its own pystray.Icon. Autostart with --minimised
    plus a later double-click of Scriptorium.bat is the everyday way to
    get two icons. A named mutex is the usual Windows answer and needs
    no new package (ctypes is stdlib).

Behaviour
    * First instance creates mutex Local\ScriptoriumSingleInstance and
      keeps the handle alive for the process lifetime.
    * First instance also creates event Local\ScriptoriumRestore and a
      daemon thread that waits on it, then posts _bring_to_front to Tk.
    * Second instance sees ERROR_ALREADY_EXISTS, pulses the restore
      event, and exits without constructing a window (so no second tray
      icon, and no CustomTkinter DPI clash).
    * _bring_to_front restores from tray if hidden, otherwise deiconify
      + lift + focus_force -- the same as the existing tray "Show" path.

2a. ctypes helpers -- scriptorium.py, after resource_path (line 137)

Insert before _autostart_command (line 152). Keep the mutex handle at
module level so Windows does not release it on GC.

Surrounding context (before): the end of resource_path.
Surrounding context (after): def _autostart_command():

Snippet:

import ctypes

_MUTEX_NAME = "Local\\ScriptoriumSingleInstance"
_RESTORE_EVENT_NAME = "Local\\ScriptoriumRestore"
_mutex_handle = None
ERROR_ALREADY_EXISTS = 183
INFINITE = 0xFFFFFFFF

def _claim_single_instance():
    """Return True if this process now owns the single-instance mutex.

    False means another Scriptorium is already running. The mutex handle
    is stored at module level so it lives until process exit.
    """
    global _mutex_handle
    kernel32 = ctypes.WinDLL("kernel32", use_last_error=True)
    _mutex_handle = kernel32.CreateMutexW(None, False, _MUTEX_NAME)
    return ctypes.get_last_error() != ERROR_ALREADY_EXISTS

def _signal_existing_instance():
    """Ask the running instance to show itself, then this process can exit."""
    kernel32 = ctypes.WinDLL("kernel32", use_last_error=True)
    handle = kernel32.OpenEventW(0x00100002, False, _RESTORE_EVENT_NAME)  # EVENT_MODIFY_STATE
    if handle:
        kernel32.SetEvent(handle)
        kernel32.CloseHandle(handle)

2b. Listen for that pulse -- Scriptorium.__init__, after tray_icon = None (line 1470)

        self._start_restore_listener()

Helper, insert just above _on_close (line 2206):

    def _start_restore_listener(self):
        """Watch the named restore event so a second launch can wake us."""
        kernel32 = ctypes.WinDLL("kernel32", use_last_error=True)
        # CreateEventW(security, manual_reset, initial_state, name)
        self._restore_event = kernel32.CreateEventW(
            None, True, False, _RESTORE_EVENT_NAME)

        def _watch():
            while True:
                kernel32.WaitForSingleObject(self._restore_event, INFINITE)
                kernel32.ResetEvent(self._restore_event)
                self._post_to_ui(self._bring_to_front)

        threading.Thread(target=_watch, daemon=True).start()

    def _bring_to_front(self):
        """Show the window whether it is visible, minimised, or in the tray."""
        if self.tray_icon is not None:
            try:
                self.tray_icon.stop()
            except Exception:
                pass
            self._finish_tray_restore()
            return
        self.deiconify()
        self.lift()
        self.focus_force()

3.2 Copyable change summary
    Why: the status bar already shows "revision N words (+/-)" in
    _refresh_status (line 1706). It does not say how much was actually
    rewritten, and there is no way to copy that line into a covering
    email. SequenceMatcher is already paid for in render_diff (line 982).

    File   : scriptorium.py
    After  : render_diff  (ends ~line 1012)

    def summarise_diff(original, revised):
        """Return a one-line British English change summary.

        Counts word-level inserts, deletes and replacements using the
        same tokenisation as render_diff. Example:
        '12 words inserted, 4 deleted, 3 replaced'
        """
        a, b = _tokenise(original), _tokenise(revised)
        matcher = difflib.SequenceMatcher(None, a, b, autojunk=False)
        inserted = deleted = replaced = 0
        word = re.compile(r"\w", re.UNICODE)
        def n_words(tokens):
            return sum(1 for tok in tokens if word.search(tok))
        for tag, i1, i2, j1, j2 in matcher.get_opcodes():
            if tag == "insert":
                inserted += n_words(b[j1:j2])
            elif tag == "delete":
                deleted += n_words(a[i1:i2])
            elif tag == "replace":
                replaced += n_words(b[j1:j2])
        parts = []
        if inserted:
            parts.append(f"{inserted} word{'s' if inserted != 1 else ''} inserted")
        if deleted:
            parts.append(f"{deleted} deleted")
        if replaced:
            parts.append(f"{replaced} replaced")
        return ", ".join(parts) if parts else "no wording changes"

    In _refresh_status, when self.last_result is set, append
    summarise_diff(self._result_source, self.last_result["revised"])
    to the existing revision clause.

    On the action bar (_build_actionbar), add a compact button
    "Copy summary" next to "Copy revision". Handler:

    def copy_change_summary(self):
        if not self.last_result:
            return
        summary = summarise_diff(self._result_source, self.last_result["revised"])
        self.clipboard_clear()
        self.clipboard_append(summary)
        self._refresh_status("change summary copied")

    Bind it in _bind_shortcuts as <Control-Shift-M> (mnemonic: suMmary),
    so it does not steal Ctrl+C inside Original.
