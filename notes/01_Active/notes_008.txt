### 2.2 Methods
Insert at: scriptorium.py, after copy_revision() (~1080).

```python
    def copy_original(self):
        """Copy the Original pane to the clipboard (no revision involved)."""
        text = self.original_box.get("1.0", "end-1c")
        if not text:
            self._refresh_status("nothing to copy")
            return
        self.clipboard_clear()
        self.clipboard_append(text)
        self._refresh_status("original copied to clipboard")

    def paste_original(self):
        """Insert clipboard text into Original at the current selection.

        An empty clipboard is reported rather than raising TclError.
        Existing content is pushed onto undo_stack so Undo restores it.
        """
        try:
            incoming = self.clipboard_get()
        except tk.TclError:
            self._refresh_status("clipboard is empty")
            return
        if not incoming:
            self._refresh_status("clipboard is empty")
            return
        self.undo_stack.append(self.original_box.get("1.0", "end-1c"))
        try:
            self.original_box.delete("sel.first", "sel.last")
        except tk.TclError:
            pass  # no selection — insert at the insertion cursor
        self.original_box.insert("insert", incoming)
        self._refresh_status("pasted from clipboard")
```

Wire in _build_actionbar(), after Undo (or in the right-hand group):

### 3.3 Close → tray (not quit)
Replace _on_close (~1155):

```python
    def _on_close(self):
        """Hide to the tray when that option is on; otherwise quit."""
        if self.cfg.get("minimise_to_tray", True):
            self.withdraw()
            self._ensure_tray_icon()
            return
        self._quit_app()

    def _quit_app(self):
        """Real shutdown: drop in-flight work, remove the icon, destroy."""
        self._invalidate_inflight()
        self._remove_tray_icon()
        self.destroy()

    def _restore_from_tray(self):
        """Single-click on the tray icon: show and raise the window."""
        self.after(0, self._restore_from_tray_ui)

    def _restore_from_tray_ui(self):
        self.deiconify()
        self.lift()
        self.focus_force()
```

Insert at: new helpers after save_config(). Use winreg (stdlib).

```python
import sys
import winreg

RUN_KEY = r"Software\Microsoft\Windows\CurrentVersion\Run"
RUN_NAME = "Scriptorium"


def autostart_command():
    pythonw = sys.executable.replace("python.exe", "pythonw.exe")
    script = os.path.abspath(__file__)
    return f'"{pythonw}" "{script}" --minimised'


def set_start_with_windows(enabled):
    """Create or delete the current-user Run entry."""
    with winreg.OpenKey(winreg.HKEY_CURRENT_USER, RUN_KEY, 0,
                        winreg.KEY_SET_VALUE) as key:
        if enabled:
            winreg.SetValueEx(key, RUN_NAME, 0, winreg.REG_SZ,
                              autostart_command())
        else:
            try:
                winreg.DeleteValue(key, RUN_NAME)
            except FileNotFoundError:
                pass
```

Call set_start_with_windows(...) from SettingsDialog._save after the
other cfg assignments.

In main():

### 3.5 Tray icon implementation sketch (ctypes, no extra dep)
A full Shell_NotifyIconW wrapper is ~80–120 lines. Put it in a new
module tray_windows.py next to scriptorium.py so the GUI file stays
readable. Responsibilities:

  * Add / update / delete NIM_ADD, NIM_MODIFY, NIM_DELETE.
  * Message window (hidden Tk or a tiny Win32 HWND) receiving
    WM_LBUTTONUP → app._restore_from_tray and WM_RBUTTONUP → popup
    with Open / Quit.
  * Icon: load a .ico if present (C:\Scriptorium\scriptorium.ico);
    otherwise LoadIcon(NULL, IDI_APPLICATION). Shipping a 16×16 /
    32×32 .ico is the one binary add; generating one later is fine.

pystray alternative (if you accept two extra packages):

    pip install pystray pillow

    Icon thread must marshal UI calls with self.after(0, ...), never
    touch Tk from the pystray thread.

Either way, _ensure_tray_icon() is idempotent (create once).

### 3.6 Risks
  * Closing the window no longer exits. Users who expect Alt+F4 to
    quit need the tray Quit item, plus a Settings off-switch.
  * A crashed tray thread with the window withdrawn looks like
    "Scriptorium disappeared". Guard with a "Quit Scriptorium" tray
    item and, during bring-up, a visible window unless --minimised.
  * pythonw vs python: if pythonw is missing, fall back to python.exe
    and accept a hidden console as a lesser evil.
  * First-run privacy notice: if start_minimised, show the dialog
    only after restore, or skip until the first visible session.
    Call _maybe_show_privacy_notice() from _restore_from_tray_ui if
    it was deferred.
