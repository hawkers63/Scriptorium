2. NEW FINDING
--------------------------------------------------------------------------------

2.1  Bug A — Placeholder sentinels collide with existing prose     MEDIUM
     Location: mask_placeholders() ~589–603, restore_placeholders() ~606–627.
     Confirmed today:

       Source:   Keep ⟦PH0⟧ and [Name]
       Masked:   Keep ⟦PH0⟧ and ⟦PH0⟧
       Restored: Keep [Name] and [Name]
       Warning:  "[Name] appeared 2 times … all occurrences were restored."

     The user's literal ⟦PH0⟧ is indistinguishable from the sentinel assigned
     to [Name]. restore_placeholders() then replaces every occurrence.
     Rare in ordinary letters, but a previous failed run that left a raw
     sentinel in Original will silently corrupt the next Process.

     notes_010 did not record this. The Markdown false-positive is fixed;
     this collision is separate.

     Remedy: nonce the sentinel per call. See Fix A.

### Fix A — Nonce placeholder sentinels
Insert at: scriptorium.py, top-level imports (add secrets) and replace
the body of mask_placeholders() (~589–603). restore_placeholders() is
unchanged; it already keys on the exact sentinel string.

```python
import secrets  # beside json / threading / urllib


def mask_placeholders(text):
    """Swap placeholders for opaque, per-call sentinels.

    A short nonce is mixed into every token so a document that already
    contains text shaped like ⟦PH0⟧ cannot collide with a fresh mask.
    Returns (masked_text, mapping) of (sentinel, original) pairs.
    """
    nonce = secrets.token_hex(3)
    mapping = []

    def _swap(match):
        sentinel = f"{_PH_OPEN}PH{nonce}_{len(mapping)}{_PH_CLOSE}"
        mapping.append((sentinel, match.group(0)))
        return sentinel

    return _PLACEHOLDER_RE.sub(_swap, text), mapping
```

    """Return (word_count, character_count) for a pane of prose."""
    words = len(re.findall(r"\w+", text, flags=re.UNICODE))

def shift_strength(current, delta):
    """Move one step along STRENGTHS, clamped at the ends."""
    idx = STRENGTHS.index(current)
    return STRENGTHS[max(0, min(len(STRENGTHS) - 1, idx + delta))]
