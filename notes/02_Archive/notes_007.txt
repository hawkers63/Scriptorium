2. IDENTIFIED BUGS & SEVERITY
--------------------------------------------------------------------------------

------------------------------------------------------------------------------
 CRITICAL — Bug 1. Stale last_result bound to the wrong source snapshot
------------------------------------------------------------------------------
 File:    scriptorium.py
 Class:   Scriptorium
 Methods: process, _on_success, _revision_is_stale, _on_diff_view_change,
          accept, copy_revision, export_file, reject, undo, clear_all,
          import_file
 Lines:   process ~861–902; _on_success ~904–937; _revision_is_stale ~945–947;
          _on_diff_view_change ~949–954; accept ~956–969; copy_revision ~979–984;
          export_file ~1019–1040; reject ~971–977

 Failure point
  process() writes self._processing_source = original as soon as a request
  starts, but self.last_result is only replaced later in _on_success.
  _revision_is_stale() and _on_diff_view_change() treat _processing_source
  as “the text last_result was built from”. That is true only until the
  next Process click.

  Deterministic sequence:
    1. Process text A. last_result = revision(A), _processing_source = A.
    2. Edit the box to B (or Process again). process() immediately sets
       _processing_source = B. last_result is still revision(A). busy=True.
    3. _revision_is_stale() compares the box (B) to _processing_source (B)
       and returns False.
    4. Accept overwrites B with revision(A) with no warning. Copy silently
       clipboards revision(A). The Clean/Inline toggle diffs revision(A)
       against B, so highlighting is nonsense.

  Compounding: only process_btn is disabled while busy. Accept, Reject,
  Copy, Undo, Clear, Import and Export stay enabled. None of Reject /
  Undo / Clear / Import increment any generation counter, and the worker
  always schedules _on_success/_on_error.

  Reject-while-busy (same text still in the box):
    reject() clears last_result and the revision pane. The in-flight
    callback then runs _on_success with original still equal to the box,
    so the “text changed while processing” warning is NOT added, and the
    dismissed revision reappears unannounced.

  Clear/Import-while-busy:
    the box no longer matches original, so a warning is appended to the
    ambiguity strip, but last_result is still published and render_diff()
    still paints a revision of content the user has just discarded.

  copy_revision() never consults _revision_is_stale() at all.

  This is a data-consistency defect, not a cosmetic race: Accept can
  commit the wrong revision onto the live original pane.

 HIGH — Bug 2. load_config() crashes on non-object JSON, or silently

------------------------------------------------------------------------------
 File:    scriptorium.py
 Functions: load_config (WT ~141–148), save_config (WT ~151–156)

 MODERATE — Bug 4. Placeholder regex consumes Markdown links and citations
------------------------------------------------------------------------------
 File:    scriptorium.py
 Constant: _PLACEHOLDER_PATTERNS (WT ~459–465), used by mask_placeholders
 Failure point
  r"\[[^\[\]\n]+\]" matches any square-bracket run, so it masks:
    * Markdown links  [the guide](https://…)
    * Numeric citations [1], [12]
    * Editorial asides [sic], [emphasis added]
  Those tokens are sent as ⟦PHn⟧ and restored later, which is harmless
  when the model cooperates, but it strips link targets from the model’s
  view and will warn/drop them if the model rearranges the sentence. The
  documented placeholders ([Name], {{Date}}, {amount}, <Date>) do not
  require this breadth. {{…}} / {…} / <Word> patterns are reasonable.

 MODERATE — Bug 8. In-flight after() callbacks outlive the window
------------------------------------------------------------------------------
 File:    scriptorium.py
 Methods: process worker (WT ~893–902), _on_success, _on_error; no

 Failure point
  The worker is a daemon thread that calls self.after(...) from the
  background thread (Tkinter is not thread-safe; this usually works on

  bare except Exception then turns into a second after(_on_error, ...).
  If the callback does run, it touches destroyed widgets.

# --- snippet 1b: helper to finish or ignore a callback ---

    def _claim_request(self, request_id):
        """Return True if this callback still owns the UI.

        Late results from a cancelled or superseded request are dropped.
        Busy is only cleared when this request is still the current one;
        cancellers (Reject, Clear, close) clear busy themselves so Process
        cannot stick on 'Working…'.
        """
        if not self.winfo_exists():
            return False
        if request_id != self._request_id:
            return False
        self.busy = False
        self.process_btn.configure(text="Process  (Ctrl+Enter)", state="normal")
        return True

    def _invalidate_inflight(self):
        """Drop any in-flight Process callback and re-enable the button."""
        self._request_id += 1
        if self.busy:
            self.busy = False
            self.process_btn.configure(text="Process  (Ctrl+Enter)",
                                       state="normal")


# --- snippet 1c: process() — snapshot cfg, stamp a request id ---

    def process(self):
        """Send the current text to the backend on a worker thread."""
        if self.busy:
            return
        original = self.original_box.get("1.0", "end-1c")
        if not original.strip():
            self._refresh_status("nothing to process")
            return

        if self.cfg.get("protect_placeholders", True):
            masked, ph_map = mask_placeholders(original)
        else:
            masked, ph_map = original, []

        self._request_id += 1
        request_id = self._request_id
        self.busy = True
        self.process_btn.configure(text="Working…", state="disabled")
        busy_note = "contacting the model…"
        if ph_map:
            busy_note = (f"protecting {len(ph_map)} placeholder(s), "
                         "contacting the model…")
        self._refresh_status(busy_note)

        system_prompt = build_system_prompt(
            self.mode_var.get(), self.strength_var.get(),
            self.tone_var.get(), self.role_var.get(),
            protect_tokens=bool(ph_map))
        cfg_snapshot = dict(self.cfg)

        def worker():
            try:
                result = run_backend(system_prompt, masked, cfg_snapshot)
                self.after(0, self._on_success,
                           request_id, original, ph_map, result)
            except BackendError as exc:
                self.after(0, self._on_error, request_id, str(exc))
            except Exception as exc:  # noqa: BLE001
                self.after(0, self._on_error,
                           request_id, f"Unexpected error: {exc}")

        threading.Thread(target=worker, daemon=True).start()


# --- snippet 1d: _on_success / _on_error ---

    def _on_success(self, request_id, original, ph_map, result):
        """Apply a completed revision if this request is still current."""
        if not self._claim_request(request_id):
            return

        warnings = []
        if ph_map:
            result["revised"], warnings = restore_placeholders(
                result["revised"], ph_map)

        if self.original_box.get("1.0", "end-1c") != original:
            warnings.append(
                "The original text changed while this was processing, so this "
                "revision reflects the earlier text. Review it carefully before "
                "accepting.")

        if self.cfg.get("check_letter_conventions", True):
            advisory = audit_letter_conventions(result["revised"])
            if advisory:
                warnings.append(advisory)

        self.last_result = result
        self._result_source = original
        render_diff(self.revised_box, original, result["revised"],
                    inline=(self.diff_view_var.get() == "Inline"))
        self._show_ambiguities(list(result.get("ambiguities", [])) + warnings)

        note = result.get("note", "")
        if ph_map and not warnings:
            note = ((note + "  ") if note else "") + (
                f"{len(ph_map)} placeholder(s) preserved")
        self._refresh_status(note or "done")

    def _on_error(self, request_id, message):
        """Surface a backend failure if this request is still current."""
        if not self._claim_request(request_id):
            return
        self._refresh_status("error")
        messagebox.showerror("Could not process", message)


# --- snippet 1e: stale check and diff toggle must use _result_source ---

    def _revision_is_stale(self):
        """True if the original box no longer matches the live revision."""
        return self.original_box.get("1.0", "end-1c") != self._result_source

    def _on_diff_view_change(self, _value=None):
        """Re-render the current revision when Clean/Inline changes."""
        if self.last_result:
            render_diff(self.revised_box, self._result_source,
                        self.last_result["revised"],
                        inline=(self.diff_view_var.get() == "Inline"))


# --- snippet 1f: cancel in-flight work on Reject / Undo / Clear / Import ---

    def reject(self):
        """Clear the revision pane and drop any in-flight request."""
        self._invalidate_inflight()
        self.revised_box.configure(state="normal")
        self.revised_box.delete("1.0", "end")
        self.revised_box.configure(state="disabled")
        self.last_result = None
        self._result_source = ""
        self._show_ambiguities([])
        self._refresh_status("revision cleared")

    def copy_revision(self):
        """Copy the live revision, refusing if the original has moved on."""
        if not self.last_result:
            return
        if self._revision_is_stale() and not messagebox.askyesno(
                "Revision may be out of date",
                "The original text changed after this revision was generated. "
                "Copy it anyway?"):
            return
        self.clipboard_clear()
        self.clipboard_append(self.last_result["revised"])
        self._refresh_status("revision copied to clipboard")

    def _on_close(self):
        """Invalidate in-flight callbacks before destroying the window."""
        self._invalidate_inflight()
        self.destroy()

### Fix 2 — Safe config load/save (Bug 2)

Replace load_config / save_config entirely. Keep the return type of
load_config() as a dict so Scriptorium.__init__ does not change, and
stash readability on the function so the privacy notice can refuse to

def load_config():
    """Load scriptorium_config.json, falling back to DEFAULT_CONFIG.

    A missing file is normal (first run). A file that exists but cannot
    be parsed, or that is valid JSON but not an object, leaves
    load_config.unreadable True so callers must not silently overwrite it.
    """
    load_config.unreadable = False
    cfg = dict(DEFAULT_CONFIG)
    try:
        with open(CONFIG_PATH, "r", encoding="utf-8") as fh:
            loaded = json.load(fh)
    except FileNotFoundError:
        return cfg
    except (json.JSONDecodeError, OSError) as exc:
        load_config.unreadable = True
        print(f"[warning] could not read config: {exc}")
        return cfg
    if not isinstance(loaded, dict):
        load_config.unreadable = True
        print("[warning] config file is not a JSON object; using defaults.")
        return cfg
    cfg.update(loaded)
    return cfg


def save_config(cfg, *, force=False):
    """Write cfg to disk. Refuses to clobber an unreadable file unless force.

    Settings-dialog saves pass force=True so the user can recover. The
    privacy-notice path must not.
    """
    if getattr(load_config, "unreadable", False) and not force:
        print("[warning] refusing to overwrite an unreadable config file")
        return
    try:
        with open(CONFIG_PATH, "w", encoding="utf-8") as fh:
            json.dump(cfg, fh, indent=2)
        load_config.unreadable = False
    except OSError as exc:
        print(f"[warning] could not save config: {exc}")

def list_ollama_models(timeout=3):
    """Return the model tags Ollama has locally, or [] if it cannot be reached.

    Queries Ollama's /api/tags endpoint so Settings can offer exactly what is
    installed rather than relying on the tag being typed exactly right.
    Never raises: a malformed payload is treated as 'nothing detected'.
    """
    try:
        req = urllib.request.Request(OLLAMA_TAGS_URL, method="GET")
        with urllib.request.urlopen(req, timeout=timeout) as resp:
            payload = json.loads(resp.read().decode("utf-8"))
    except (urllib.error.URLError, json.JSONDecodeError, OSError, ValueError):
        return []
    if not isinstance(payload, dict):
        return []
    raw = payload.get("models") or []
    if not isinstance(raw, list):
        return []
    names = []
    for item in raw:
        if isinstance(item, dict):
            name = item.get("name") or item.get("model") or ""
        elif isinstance(item, str):
            name = item
        else:
            name = ""
        if name:
            names.append(name)
    return sorted(names)
