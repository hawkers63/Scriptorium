2. Detailed Architectural Proposals
-----------------------------------

### A. Multi-file / folder drop → batch handoff

State impact:
  - No new persistent state. Transient: list of validated paths, optional
    output directory chosen via filedialog.
  - Reuses BATCH_SUFFIXES (4724) and `_run_batch_mode` argv contract.
  - GUI session stays on the single-document contract; batch runs in a
    subprocess (`sys.executable` + `--batch …`) so the live window’s
    cancel/mutex story is untouched (v2.19 deliberately skips the mutex for
    `--batch`).

Config schema deltas: none.

Performance:
  - Path enumeration for a dropped folder must be bounded (e.g. non-
    recursive first cut, or recursive with a hard cap of 200 files and a
    clear message). Reading file bodies stays in the batch process.

DOCX: continue to gate through existing `read_docx` / optional import;
batch already handles .docx the same way.

### B. Preset pack import / export

State impact:
  - Pack file schema (versioned):
      {
        "format": "scriptorium.preset_pack",
        "version": 1,
        "presets": { "<name>": {mode, strength, role, tones} }
      }
  - Import merges through `normalise_user_presets` after union with current
    `cfg["user_presets"]`, so reserved WRITING_PRESETS names and the manager
    label stay protected. Collisions: skip with a repair-style message list
    (same shape as load_config.repair_warnings), never silently overwrite
    unless the user ticks “Replace existing names”.

Config schema deltas: none required. Optional later:
  `"last_applied_preset": ""`  # display-only; do not auto-apply on startup
                               # (ROADMAP v2.x explicitly avoided persisting
                               # last-used as a silent override of defaults)

Performance: trivial JSON; packs capped at MAX_USER_PRESETS entries.

### C. Soft tone conflicts

State impact:
  - New module-level `TONE_SOFT_CONFLICTS: dict[frozenset[str], str]` parallel
    to `TONE_CONFLICTS` (475–489).
  - New pure helper `tone_soft_conflict_message(tones) -> str` (mirror of
    `tone_conflict_message` at 492).
  - `validate_tones` UNCHANGED for hard conflicts (sole authoritative hard
    boundary). Soft messages surface only in TonePickerDialog status /
    Apply confirmation.
  - Optional cfg flag `"acknowledge_soft_tone_conflicts": True` default —
    when False, Apply on a soft conflict requires an explicit yes/no.

Prompt calibration (mandatory before ship):
  - Run Ollama llama3.1:8b and Claude Sonnet on fixed fixtures for each soft
    pair (dominant order both ways). Pass criterion: no new facts, no
    emboldened certainty, no invented offers — same anti-embellishment close
    already in build_tone_instruction (1050–1060). If a soft pair still
    injects content under Substantial strength, either tighten the shared
    guard or promote the pair to hard TONE_CONFLICTS.

### D. Configurable reading_wpm + revision readability

State impact / config schema deltas:
  DEFAULT_CONFIG += `"reading_wpm": 200`
  normalise_config: clamp to int 100..400; non-numeric → 200.
  reading_metrics(text, wpm=200) uses the argument for minutes.
  _refresh_status: when last_result present and revised word count ≥ 20,
  append `revision {label} · {time_text}` beside the existing word delta.

Performance: Flesch is O(n) over words; already acceptable on keystroke-
driven refresh for Original; same cost once more for revised text is fine.

### E. Streaming preparation (design only)

Product decisions still required from Mark (verbatim from ROADMAP v2.25 /
notes_021 — recorded here so engineering does not guess):

  P1. May the Suggested-revision pane show an unreviewed partial draft
      while tokens arrive?
        a) No — keep spinner/status only until a complete JSON object parses.
        b) Yes — show a clearly labelled “partial / unreviewed” draft.
  P2. If the stream fails after partial delivery:
        a) Discard partial; show the error; leave prior accepted state alone.
        b) Keep labelled partial; never silently retry into the same pane.

Engineering seam already present (do not break it):
  `_request_with_retries(..., response_reader=...)` at 1315–1406.
  Docstring at 1323–1328 already states: a reader that has shown partial
  output must not allow transparent retry from the beginning.

Proposed reader contracts (not for paste yet):
  - Anthropic: POST with `"stream": true`; read `text/event-stream`; assemble
    content_block_delta text; only call `_extract_json` on message_stop.
  - Ollama: `"stream": true`; read NDJSON lines; concatenate message.content
    deltas; parse JSON on final `done: true`.
  - When streaming UI is eventually enabled: pass
    `transient_statuses=set()` or short-circuit retries after the first
    byte is delivered to the UI callback; cancel_event remains the wake
    path for Reject/Clear/Import.

Performance: streaming reduces time-to-first-byte perception only; total
tokens unchanged. JSON-in-stream still needs a complete object for
ambiguities/note — partial display of raw envelope fragments is explicitly
why this stays deferred.

### Snippet A1 — drop path classifier (near _handle_dropped_paths)

def classify_dropped_paths(paths, suffixes=BATCH_SUFFIXES, max_files=200):
    """Classify an Explorer drop into single / batch / rejected.

    Returns a dict with keys:
      kind: "single" | "batch" | "empty" | "too_many" | "unsupported"
      files: list[str]  # existing files whose suffix is allowed
      reason: str       # human-readable when kind is not single/batch

    Folders contribute their *immediate* children only (non-recursive) so a
    careless drop of a home directory cannot enqueue thousands of files.
    """
    files = []
    for path in paths:
        if os.path.isdir(path):
            try:
                names = os.listdir(path)
            except OSError as exc:
                return {"kind": "unsupported", "files": [],
                        "reason": f"Could not read folder: {exc}"}
            for name in names:
                candidate = os.path.join(path, name)
                if (os.path.isfile(candidate)
                        and os.path.splitext(candidate)[1].lower()
                        in suffixes):
                    files.append(candidate)
        elif (os.path.isfile(path)
              and os.path.splitext(path)[1].lower() in suffixes):
            files.append(path)
    # De-duplicate while preserving order.
    seen = set()
    ordered = []
    for path in files:
        key = os.path.normcase(os.path.abspath(path))
        if key not in seen:
            seen.add(key)
            ordered.append(path)
    if not ordered:
        return {"kind": "empty", "files": [],
                "reason": "No .txt, .md or .docx files were found."}
    if len(ordered) > max_files:
        return {"kind": "too_many", "files": ordered[:max_files],
                "reason": (f"Found {len(ordered)} files; refuse more than "
                           f"{max_files} in one drop.")}
    if len(ordered) == 1 and len(paths) == 1 and os.path.isfile(paths[0]):
        return {"kind": "single", "files": ordered, "reason": ""}
    return {"kind": "batch", "files": ordered, "reason": ""}


### Snippet A2 — replace body of Scriptorium._handle_dropped_paths

def _handle_dropped_paths(self, paths):
    """Validate a completed Explorer drop on Tk's event thread.

    One ordinary document still loads into Original. A folder or several
    matching documents offer the existing headless batch programme instead
    of a dead-end 'drop one file' dialogue.
    """
    verdict = classify_dropped_paths(paths)
    if verdict["kind"] == "single":
        self._load_file_path(verdict["files"][0], confirm_replace=True)
        return
    if verdict["kind"] != "batch":
        messagebox.showinfo(
            "Nothing to open",
            verdict["reason"] or "Scriptorium could not use that drop.",
            parent=self,
        )
        return

    count = len(verdict["files"])
    if not messagebox.askyesno(
            "Run batch on dropped files?",
            f"{count} document(s) were dropped. Open them in the Original "
            "pane one at a time is not supported; run a headless batch "
            "instead?\n\nYou will be asked for an output folder. The "
            "current window stays as it is.",
            parent=self):
        return
    out_dir = filedialog.askdirectory(title="Batch output folder")
    if not out_dir:
        return
    # Stage inputs into a temporary directory listing so batch mode keeps
    # its existing INPUT_DIR contract without rewriting argv parsing.
    staging = tempfile.mkdtemp(prefix="scriptorium_drop_")
    try:
        for src in verdict["files"]:
            dest = os.path.join(staging, os.path.basename(src))
            # Never overwrite silently inside staging.
            if os.path.exists(dest):
                stem, ext = os.path.splitext(os.path.basename(src))
                dest = os.path.join(staging, f"{stem}_{secrets.token_hex(3)}{ext}")
            shutil.copy2(src, dest)
    except OSError as exc:
        messagebox.showerror("Batch staging failed", str(exc), parent=self)
        return

    # Launch a sibling process; do not import _run_batch_mode on the UI thread.
    cmd = [
        sys.executable,
        os.path.abspath(sys.argv[0]),
        "--batch", staging,
        "--out", out_dir,
        "--mode", self.mode_var.get(),
        "--strength", self.strength_var.get(),
        "--role", self.role_var.get(),
    ]
    try:
        subprocess.Popen(cmd, close_fds=True)
    except OSError as exc:
        messagebox.showerror("Batch launch failed", str(exc), parent=self)
        return
    self._refresh_status(
        f"batch started for {count} file(s) → {os.path.basename(out_dir)}")


### Snippet B1 — pack helpers (near normalise_user_presets ~688)

PRESET_PACK_FORMAT = "scriptorium.preset_pack"
PRESET_PACK_VERSION = 1


def export_preset_pack(user_presets, path):
    """Write a shareable preset pack. Returns (ok: bool, detail: str)."""
    clean = normalise_user_presets(user_presets)
    document = {
        "format": PRESET_PACK_FORMAT,
        "version": PRESET_PACK_VERSION,
        "presets": clean,
    }
    try:
        with open(path, "w", encoding="utf-8", newline="\n") as fh:
            json.dump(document, fh, indent=2, ensure_ascii=False)
            fh.write("\n")
    except OSError as exc:
        return False, str(exc)
    return True, f"exported {len(clean)} preset(s)"


def import_preset_pack(path, existing, *, replace_existing=False):
    """Merge a pack into existing user_presets.

    Returns (merged_dict, messages: list[str]). Invalid packs yield
    ({}, ["…"]) without raising, matching the config-repair style.
    """
    messages = []
    try:
        with open(path, "r", encoding="utf-8-sig") as fh:
            loaded = json.load(fh)
    except (OSError, json.JSONDecodeError) as exc:
        return dict(existing), [f"Could not read preset pack: {exc}"]
    if not isinstance(loaded, dict) or loaded.get("format") != PRESET_PACK_FORMAT:
        return dict(existing), ["File is not a Scriptorium preset pack."]
    incoming = loaded.get("presets", {})
    if not isinstance(incoming, dict):
        return dict(existing), ["Pack 'presets' field is not an object."]

    merged = dict(existing)
    if replace_existing:
        # Drop only names that the pack successfully validates.
        validated = normalise_user_presets(incoming)
        for name in validated:
            merged.pop(name, None)
        incoming = validated
    # Union then re-validate so reserved names and caps still apply.
    trial = dict(merged)
    trial.update(incoming if isinstance(incoming, dict) else {})
    issues = {"messages": [], "omitted": 0}
    clean = normalise_user_presets(trial, issues=issues)
    messages.extend(issues["messages"])
    if issues["omitted"]:
        messages.append(f"{issues['omitted']} further pack issue(s) omitted.")
    return clean, messages

def tone_soft_conflict_message(tones):
    """Return the first soft-conflict advisory for a selection, or "".

    Soft conflicts never raise inside validate_tones(); they are UI guidance
    only. Promote a pair into TONE_CONFLICTS after live-model calibration if
    it reliably injects content or certainty.
    """
    selected = set(tones)
    for pair, message in TONE_SOFT_CONFLICTS.items():
        if pair.issubset(selected):
            return message
    return ""

def reading_metrics(text, wpm=200):
    """Return (grade_label, minutes) for the given text, or None if empty.

    wpm is words-per-minute for the reading-time estimate (config-
    driven; default 200). Grade labels remain Flesch Reading Ease bands.
    """
    words = text.split()
    word_count = len(words)
    if word_count == 0:
        return None
    # ... existing syllable / score logic unchanged ...
    rate = max(int(wpm), 1)
    minutes = word_count / rate
    return label, minutes
